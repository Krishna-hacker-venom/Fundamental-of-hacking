# RFC (Request for Comments)

## What is RFC?

**RFC** stands for **Request for Comments**.

An RFC is a **technical document** that describes how something related to the Internet, networking, or other technical standards should work.

Think of an RFC as a **technical specification or rulebook**.

## What does the number mean?

Numbers such as **1001, 793, or 1918** are simply **unique identification numbers assigned to RFC documents**.

For example:

- **RFC 1001** → RFC document #1001
- **RFC 793** → RFC document #793
- **RFC 1918** → RFC document #1918

The number itself usually **does not describe the technology**. You need to look at the RFC's title or content to know what it is about.

## Are RFC numbers built-in or manually created?

RFC numbers are **assigned during the RFC publication process**. They are not a built-in part of the protocol or technology.

Think of an RFC number like a document serial number:

```text
RFC 1000
RFC 1001
RFC 1002
RFC 1003
```

So:

> **RFC 1001 = the RFC document identified by number 1001.**

The number is mainly used to **uniquely identify that particular RFC document**.

## Example

**RFC 1001** is about **NetBIOS over TCP/IP**.

Therefore:

```text
RFC      = Request for Comments
1001     = Document identification number
RFC 1001 = A specific RFC document
```
